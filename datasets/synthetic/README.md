# Dữ liệu tổng hợp

Fixture đầu-cuối ban đầu nằm ở `../samples/small_store.json`, đã ghi rõ là dữ liệu
tổng hợp trong UI và báo cáo mô phỏng. Chưa có generator chiến dịch kích thước lớn
hoặc dataset hiệu chuẩn từ cửa hàng thật. Không tự tạo dữ liệu rồi gọi là dữ liệu
quan sát. Khi thêm generator cần ghi seed, phiên bản, đơn vị, constraints và hash.
